## 🌟 关于

Cogna 是一个代码分析平台，最初的目标是实现基于 **代码属性图（Code Property Graph）** 的静态分析和搜索引擎，这是我学习和实践 **MoonBit**、**编译器技术** 的练习作品，也是我对 **Vibe Coding** 编程方法的首次失败尝试。

相比「古法编程」的编程方法，我比平时更快地遇到了缺陷爆炸、架构腐化等问题，这让我回归 Vibe + 古法的混合编程方法。

接下来，我将基于我自身的软件工程经验，通过古法 + AI 的混合方法，通过原子化的方式，自底向上一点点地构建出最终的 Cogna 平台。

下一阶段的工作将聚焦于 [**parkit**](https://github.com/cogna-dev/parkit)，我希望打造一个兼具教学和实用属性的，兼容多种语法输入和生成器算法的解析器框架，它并非「另一个解析器生成器」，而是用于揭示各种生成器的内部原理，同时我希望降低开发者在学习编写解析器时的摩擦，让它在 DX（开发者体验）方面达到行业一流水准。
